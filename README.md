# DroidShell Support & Open Source Notices

This repository contains support information, issue tracking and open source license notices for DroidShell.

DroidShell is a proprietary application for Apple platforms. The source code of DroidShell is not published in this repository.

## Support

For support, questions or license-related requests, contact:

info@emudev.de

## Issues

Use the GitHub Issues tab to report bugs, connection problems, device-specific behavior or feature requests.

Please include:

- Apple platform and OS version
- Apple device model
- Android version
- Connection mode used
- Whether Wireless debugging or classic TCP/IP ADB was used
- Steps to reproduce the issue

Do not post private IP addresses, pairing codes, screenshots containing personal data or device identifiers.
