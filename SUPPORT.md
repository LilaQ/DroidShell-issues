## Reporting a Bug

When reporting a bug, please include:

- DroidShell app version
- iOS version
- iPhone or iPad model
- Android device model
- Android version
- Connection mode:
  - Wireless debugging
  - Classic ADB TCP/IP
- Whether pairing succeeds
- Whether connecting succeeds
- The exact error message shown in DroidShell

Please do not include:

- Wireless debugging pairing codes
- Private IP addresses
- Personal device identifiers
- Screenshots containing sensitive information

## Common Wireless Debugging Notes

Android Wireless debugging uses two different ports:

1. Pairing port  
   Used only when pairing with a pairing code.

2. Debug port  
   Used after pairing to connect to the device.

The debug port can change when Wireless debugging is restarted. If DroidShell cannot connect, check the current IP address and port shown on the Android Wireless debugging screen.
